# Vitrina WordCamp

Theme demostrativo para charla **“No todo lo que vende necesita WooCommerce”**.

## Incluye

- Landing responsive.
- CPT nativo `producto`.
- Meta box con precio, descripción corta y enlace de contacto.
- Templates de portada, producto individual y archivo.
- Cero plugins requeridos.

## Uso

1. Activar **Vitrina WordCamp**.
2. Crear una página y asignar template **Home WordCamp**.
3. Seleccionarla como página de inicio.
4. Agregar productos desde menú **Productos**.

Código intencionalmente pequeño. Objetivo: enseñanza, no e-commerce completo.
